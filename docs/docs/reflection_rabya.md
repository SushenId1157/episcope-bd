My Area: Outbreak Detection and Disease Forecasting

Question 1: What does "normal" mean here?

Answer: "Normal" means the average number of cases usually reported for a specific disease in a specific district during the same period in previous years.

Question 2: What would be the problem if we compared only with the last few weeks? (Think about the rainy season.)

Answer: Disease cases may naturally increase during the rainy season. Comparing only with recent weeks could create false alerts because seasonal changes would not be considered.

A Decision and Why
Question 3: What changes and what does not change when k increases from 3 to 4?

Answer: Increasing k from 3 to 4 reduces false alerts from 6.03 to 3.11. Sensitivity remains the same at 91.4%, so outbreak detection ability does not decrease. Therefore, k = 4 gives fewer false alarms with the same detection performance.

What I Learned
Question 4: What new things did you learn from this part?

Answer: I learned how to detect unusual disease outbreaks by comparing weekly cases with historical patterns. I also learned how seasonal changes affect disease forecasting and how choosing the right threshold helps reduce false alerts.
