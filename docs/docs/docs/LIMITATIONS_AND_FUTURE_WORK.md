# Limitations and Future Work

## 1. Introduction

EpiScope provides a public-health disease surveillance platform with data processing, analytics, forecasting, resource allocation, and interactive visualization. However, like any data-driven system, it has some limitations and opportunities for future improvement.

## 2. Current Limitations

### 2.1 Synthetic Data

The project uses synthetic data to demonstrate its pipeline and analytical capabilities. Although synthetic data is useful for testing, it may not fully represent real-world disease patterns, reporting delays, or healthcare conditions.

### 2.2 Forecasting Uncertainty

Disease forecasting depends on historical observations and model assumptions. Unexpected outbreaks, changes in reporting practices, or other external factors may affect prediction accuracy.

### 2.3 Geographic Coverage

The current dashboard focuses on district-level surveillance. More detailed information at the sub-district or facility level could provide better local insights.

### 2.4 Resource Allocation Assumptions

The resource allocation model depends on estimated demand, available stock, and budget constraints. Actual healthcare needs may change quickly, so the model's recommendations require regular updates and human review.

### 2.5 Data Availability

The usefulness of disease surveillance depends on the quality, completeness, and timely availability of incoming data. Missing or delayed records may affect analytical results.

## 3. Future Work

### 3.1 Integration with Real Health Data

Future development could integrate verified and properly governed public-health datasets from healthcare facilities and official reporting systems.

### 3.2 Improved Forecasting Models

Additional forecasting methods could be evaluated and compared to improve prediction accuracy and uncertainty estimation.

### 3.3 More Detailed Geographic Analysis

The dashboard could be extended to support upazila-level and facility-level analysis where reliable data is available.

### 3.4 Real-Time Data Updates

Automated data ingestion and scheduled dashboard updates could help users access more recent surveillance information.

### 3.5 Enhanced Resource Planning

Future versions could consider transportation costs, delivery times, storage capacity, and changing resource demand when making allocation recommendations.

### 3.6 Expanded Dashboard Features

Additional features could include customizable reports, downloadable analytical summaries, and more flexible filtering options.

## 4. Conclusion

EpiScope provides a foundation for data-driven disease surveillance and healthcare resource planning. Addressing its current limitations and implementing the proposed improvements could make the platform more accurate, scalable, and useful for public-health decision-making. Any future deployment using real patient data should maintain strict privacy, security, and data governance standards.
